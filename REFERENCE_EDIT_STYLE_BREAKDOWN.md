# Reference video: how it's edited (techniques only, not content)

Source: "Claude + Google Flow = Full Stickman Animations on Autopilot 2.0" (The AI Blueprint, 6:46).
Based on the YouTube transcript and 85 low-res preview frames (about one every 5 s). Timings are approximate, to within about 5 s.

**Overall:** no face on camera. Voiceover runs over a dark navy background, with a new visual every 3 to 5 s. The colour code stays the same throughout: white text, yellow for the key word, green for success, red for problems.

## Where Dex's version can differ
- **A face on camera.** The reference has none, so Dex hosting from the studio is already a clear point of difference. Cut between Dex and the graphics.
- **Brand palette:** charcoal background instead of navy, neon green (#39FF14) instead of yellow for highlights, electric blue (#6366F1) for secondary info, warm amber (#FFB86C) for warnings.
- **Fonts and framing:** use your own. Copy the techniques, not the exact look.

## Rules for the other-channels section
- Screenshot the channels yourself and use only stats visible on the page that day. Add the date if the numbers will age.
- Keep each card brief and talk over it (commentary, not a re-upload).
